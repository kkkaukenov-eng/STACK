# STACK — готовый сайт для GitHub Pages

Статический сайт компьютерного клуба STACK в Семее. HTML, CSS и JavaScript, без сборки, платных сервисов, npm start и собственной базы персональных данных.

## Быстрый просмотр

Распакуйте ZIP и откройте **index.html** в современном браузере. Не открывайте HTML прямо внутри ZIP: соседние файлы стилей и скриптов могут не загрузиться. Для перехода в WhatsApp нужен интернет. На iPhone приложение «Файлы» может показывать только предпросмотр HTML без JavaScript; полноценную работу проверяйте в Safari после публикации или в браузере компьютера.

## Публикация на GitHub Pages для новичка

1. Войдите в GitHub и создайте новый репозиторий, например `stack-club`. Для бесплатной публикации выберите Public. Можно включить создание README, чтобы сразу появилась ветка main.
2. **Распакуйте ZIP. Сам архив загружать вместо сайта нельзя.**
3. В репозитории выберите **Add file → Upload files**. Загрузите содержимое распакованного проекта: index.html, папки css, js, assets и остальные файлы. На компьютере удобно перетащить файлы и папки в окно загрузки вместе.
4. **index.html должен быть сразу в корне репозитория**, рядом с папками css, js и assets, а не внутри дополнительной папки stack или STACK-github-pages. Структуру вложенных папок сохраните. Не создавайте один файл с названием «images» вместо папки.
5. Нажмите **Commit changes**. Не нужно вписывать новый код внутрь готовых файлов: в них всё уже есть.
6. Откройте **Settings → Pages**. В **Build and deployment → Source** выберите **Deploy from a branch**. Укажите **main** и **/(root)**, затем **Save**.
7. Дождитесь успешного задания Pages во вкладке Actions. Ссылка появится в Settings → Pages: обычно `https://ВАШ-ЛОГИН.github.io/stack-club/`.
8. Откройте ссылку и проверьте форму, оригинальный прайс и мобильное меню. При 404 проверьте регистр имени `index.html`, выбранную ветку и нахождение файла в корне. При старом отображении обновите страницу без кеша.

Публикация из папки /docs тоже возможна, но тогда весь проект, включая index.html, должен находиться внутри docs и в настройках нужно выбрать /docs.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
Разбор 404: https://docs.github.com/en/pages/getting-started-with-github-pages/troubleshooting-404-errors-for-github-pages-sites

## Файлы

| Файл | Назначение |
|---|---|
| index.html | Структура, форма, основные заголовки и метаданные |
| css/style.css | Цвета, адаптивная сетка, состояния и оформление |
| js/data.js | Цены, прежние цены, характеристики, контакты, бонусы, спецпакеты, вакансия и FAQ |
| js/main.js | Переключатели, окна, расчёт времени/стоимости, WhatsApp, копирование |
| assets/icons/favicon.svg | Простая геометрическая эмблема |
| assets/images/original-price.jpg | Предоставленный прайс без интерфейса телефона |
| assets/images/social-preview.png | Графическая карточка для превью ссылки |
| CHECKS.md | Проверки и известные ограничения |

## Где менять информацию

Откройте js/data.js в текстовом редакторе (UTF-8). Сохраните кавычки, запятые и скобки.

- `club`: основной телефон, WhatsApp (цифры без плюса), адрес, ориентир, Instagram, часовой пояс и число ПК.
- `common`: общие CPU, RAM и GPU.
- `zones`: названия, модели оборудования, частоты мониторов, цены. Массивы `prices` и `old` идут строго в порядке `tariffs`: час, 2+1, 3+2, утро, день, ночь. Для VIP массив old пустой.
- `tariffs`: названия, длительность и фиксированные интервалы. Если меняете интервалы, синхронно меняйте duration; ночной пакет имеет duration 10.
- `specials`, `specialNote`: школьный и студенческий пакеты, условия покупки.
- `bonuses`, `bonusNote`, `kaspi`: бонусы и тексты условий.
- `job`: отдельный телефон вакансии и обязанности. Не заменяйте им club.whatsapp.
- `faq`: вопросы и ответы. При изменении фактов проверьте также соответствующие ответы.

На первом экране и в контактном заголовке есть редакционные тексты с числом ПК и адресом: при изменении этих фактов обновите их в index.html, а также description и превью. Цвета меняются через переменные в начале CSS.

## Фотографии и визуальный стиль

Сайт использует графику, типографику и геометрию, а не вымышленный интерьер. Текстовое написание STACK и простая эмблема — адаптация для проекта, не заявление об оригинальности логотипа клуба. Игровые карточки оформлены текстом без сторонних рекламных изображений.

Реальные фото интерьера можно положить в assets/images, сжать в WebP/JPEG и добавить в раздел `about` в index.html, например:

```html
<img src="assets/images/interior-01.webp" alt="Реальный интерьер компьютерного клуба STACK" width="1200" height="800" loading="lazy" style="width:100%;height:auto;border-radius:10px">
```

Добавляйте только реальные фото клуба с разрешением на использование. Не вставляйте интерфейс Instagram. Второстепенные фото используйте с loading="lazy". Сейчас на странице нет тяжёлых растровых изображений: прайс загружается по отдельной ссылке.

После получения URL сайта замените относительный `og:image` в index.html на полный URL вида `https://ВАШ-ЛОГИН.github.io/stack-club/assets/images/social-preview.png`; это повышает совместимость превью с соцсетями. Добавьте `og:url` с реальным адресом сайта. До публикации реальный URL неизвестен, поэтому он не выдуман.

## Как работает заявка

1. Посетитель выбирает зону и пакет, дату/время, количество ПК, вводит имя и телефон и даёт согласие.
2. Форма показывает окончание сессии и ориентировочную сумму: цена пакета × число ПК. Бонусы дополнительно не вычитаются.
3. Для утреннего, дневного и ночного пакетов начало закреплено. Дата ночного пакета — дата начала в 22:00, окончание на следующий день в 08:00. В пакетах 2+1 и 3+2 учитывается 3 и 5 часов.
4. Кнопка открывает `https://wa.me/77011040000?text=...` с закодированным сообщением. Посетитель сам нажимает «Отправить» в WhatsApp.
5. Администратор подтверждает наличие, соседние места и стоимость. Только тогда бронь действительна.

Ничего не сохраняется в localStorage, cookie или собственной базе. Сайт не видит отправку сообщения, не утверждает, что заявка отправлена, и не показывает фиктивные свободные места. Если WhatsApp не открылся, под кнопкой есть повторная ссылка. Оплата и реквизиты банковской карты на сайте не собираются.

Спецпакеты указаны только для STANDART. Для полного трёхчасового сеанса форма предлагает начало 08:00–16:00 с окончанием не позднее 19:00. Покупку в разрешённые часы и остальные условия подтверждает администратор; сайт не проводит покупку. Проверка будущего времени использует Asia/Almaty независимо от часового пояса браузера, но точность текущего времени зависит от часов устройства.

## Для будущего автоматического бронирования

Потребуется отдельный backend/API и база данных: GitHub Pages сам серверный код не выполняет. Нужны реальные компьютеры и зоны, расписание, статусы броней, административная панель, серверная валидация дат/тарифов и часового пояса. Проверку пересечений нужно выполнять атомарно в транзакции: `existing.start < new.end AND existing.end > new.start`, с блокировкой/ограничением на конкретный ПК, чтобы параллельные заявки не забронировали одно место. Для групп назначать все нужные ПК одной транзакцией. Нужны отмена и срок резервирования, ограничения частоты запросов и доступ администратора. Секреты и ключи — только на сервере, никогда в этом репозитории. При хранении контактных данных потребуется согласованная политика хранения и удаления. Базовый сайт работает без этого.

## Источники и что требует уточнения

- Цены, бонусы, STANDART и VIP сверены с предоставленными изображениями; COMFORT перенесён из подробного задания, отдельного исходного изображения COMFORT среди доступных файлов нет.
- Актуальность цен, скидок, Kaspi RED и вакансии дополнительно не проверялась. Сроки скидок не придуманы.
- На миниатюре профиля есть анонс 7-дневного абонемента. Уверенно прочитать все данные и условия нельзя, поэтому на сайт он не вынесен. Указанные в задании 5 000 ₸ для школьников и 6 000 ₸ для студентов требуют подтверждения по оригиналу; часы, зоны и ограничения неизвестны.
- Конкурс видеороликов виден частично. Не опубликован как действующая акция: нужны полные правила, сроки, призы, критерии и подтверждение актуальности.
- Механика бонусов неизвестна: сайт не называет их денежным кешбэком и не обещает вывод.
- Ссылка 2ГИС — поиск по имени и адресу, не выдуманная карточка или координаты.
